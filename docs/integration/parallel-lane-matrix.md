## Shared rules

- Each hot path has one owner. `python3 -m integration lanes` validates the machine-readable registry.
- No lane should pull another lane merely to continue. Exchange `pg-observation-0.1`, manifests, fixtures, capability reports, and handoffs instead.
- Source lanes emit source-native observations, not canonical IDs. Identity, claims, build, and query lanes consume them through adapters.
- Every draft PR must include scope, changed paths, commands, tests, assumptions, compatibility seams, known risks, data/rights notes, and merge considerations.
- The integration lane evaluates combinations after merges; it does not authorize launch.
